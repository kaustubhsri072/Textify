# Textify 🎵📝

Convert your Spotify playlists into beautifully formatted text files! Textify is a desktop application that lets you easily backup, share, and export your Spotify playlists into a clean, readable text format.

## ✨ Features

- **Easy Export:** Quickly convert any Spotify playlist into a text document.
- **Beautiful Formatting:** Exports are cleanly formatted and easy to read.
- **Simple Interface:** An intuitive, modern design that gets out of your way.
- **Offline Backups:** Keep a permanent, offline record of your favorite playlists.

## 🚀 How to Download (For Users)

1. Go to the [Releases](../../releases) page.
2. Download the latest `Textify Setup.exe` file.
3. Run the installer and follow the instructions.
4. Launch Textify and start exporting!

## 💻 Development Setup (For Developers)

If you'd like to run Textify from source or contribute to the project, follow these steps:

### Prerequisites
- Node.js installed on your machine.
- Git installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Textify.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Textify
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the app in development mode:
```bash
npm start
```

### Building the App
To package the app into a distributable `.exe` file:
```bash
npm run build
```
The compiled installer will be available in the `dist/` folder.
