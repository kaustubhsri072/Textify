How to create your Spotify API App

  1. Go to the Spotify Developer Dashboard and log in with your Spotify account.
  2. Click "Create App" — give it any name and description.
  3. Set the Redirect URI to:
    http://127.0.0.1:8888/callback
  4. Under "Which API/SDKs are you planning to use?", select Web API.
  5. Click Save, then go to Settings to find your Client ID and Client Secret.

How to use .txt Import

This feature is designed for AI workflows (like ChatGPT).

Recommended AI Prompt

Act as an expert music curator and data parser. I have attached a text file containing a large master playlist of songs. I want you to analyze every track and split them into distinct, sonically cohesive sub-playlists. Here are my specific ideas for playlists I definitely want: 1. [Insert Playlist Idea 1, e.g., Late Night Drives - Chill, moody, low-tempo] 2. [Insert Playlist Idea 2, e.g., Heavy Hype - Aggressive, high-BPM, gym music] 3. [Insert Playlist Idea 3, e.g., Cruising - Stable rhythm, upbeat sing-alongs] **STRICT RULES FOR CURATION:** 1. **The Energy Filter:** You must strictly avoid "vibe clashes." Pay close attention to tempo, beat drops, and production style. Do not put an aggressive, fast-paced trap song into a chill, melodic playlist just because it's by the same artist. 2. **The "Leftover" Protocol:** I want to use as many songs from the original list as possible without forcing them where they don't belong. After filling my requested playlists, analyze the remaining unused songs. Group them by their sonic similarities and create 1 to 3 NEW, cleverly named playlists for them. 3. **Format Preservation:** You must output the newly created playlists as separate downloadable .txt files. The formatting of the text inside these new files MUST perfectly match the formatting of the original uploaded file (including headers, columns, spacing, and footers).

  1. Export a massive playlist to .txt using Textify.
  2. Give the .txt to an AI and ask it to sort/filter it into multiple playlists based on your preferences.
  3. Click Import .txt here and select the AI's new text file. Textify will instantly read the URLs and build a new playlist for you!
